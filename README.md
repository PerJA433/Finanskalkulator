# Finanskalkulator

Et modulært verdsettingsverktøy for å dobbeltsjekke håndregning i corporate finance. Bygget som et lærings- og kontrollhjelpemiddel — ikke som primærkilde i innleveringer.

## Moduler

- **Obligasjon** — pris fra YTM og YTM fra pris (numerisk løsning). Støtter zero-coupon, halvårlige kuponger og Yield to Call.
- **Aksje (DDM)** — Gordon growth-modellen, med vekstrate enten lagt inn direkte eller regnet fra retention rate × avkastning på ny investering.
- **DCF / EV** — neddiskonterte frie kontantstrømmer med terminalverdi, og bro fra enterprise value til aksjekurs (gjeld, overskuddskontant, antall aksjer).
- **Kredittrisiko** — zero-coupon obligasjon med misligholdsrisiko: lovet YTM, forventet utbetaling, forventet avkastning (EAR) og kredittspread.

## Funksjoner

- Språkbytte mellom norsk og engelsk
- Mellomregning kan slås av og på for hvert svar
- Kjører rett i nettleseren, ingen installasjon

## Merk

Dette er et verktøy for å verifisere egne utregninger. Tall som skal inn i faktiske oppgaver eller analyser bør komme fra etterprøvbar programvare (Excel, R, Stata).
